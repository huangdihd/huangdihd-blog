# 盲盒

世界上好多的盲盒, 在大厦的店里, 在街边的地上。有的盲盒大, 有的盲盒小, 有的盲盒精致, 有的盲盒粗糙。但唯一不变的, 是在你买下它, 打开它之前, 你永远不知道里面有什么。无论在哪, 总有人拿出自己从盲盒里获得的东西, 勋章, 手枪, 钻石, 一摊粪便, 一个闹钟, 一个可以锁住全身的锁, 一些足以乱真的假钞。我不喜欢盲盒, 我无法得知里面到底有什么, 我却需要为了我需要的东西支付代价。但如果我什么都不买, 我就什么也没有, 这里的东西好像只在盲盒里售卖, 甚至是明天的早餐。我思考过无数次, 如果我只得到了一顿糟糕的早餐, 我到底应不应该为它付出代价, 但早餐店的招牌总是挂着那些得到精致早餐的人, 正在享受他们的早餐。有的盲盒, 我一辈子可能只能买一次, 一旦错过了机会, 那个卖家我就再也找不到, 它真的值得吗, 在看到他的内容之前, 我不知道。我会买这些盲盒吗, 我会, 我必须会, 因为没有了它, 我什么也得不到。

——2026.6.2早晨
