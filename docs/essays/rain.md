# 雨

今天下雨了, 很大, 在短暂的时间内或许可以算得上是倾盆, 或许这样的雨也只会这样短暂的出现吧. 下雨, 总要意味着一些不寻常的事情发生, 又或许下雨本身就不寻常, 又或者不在不寻常时下的雨, 没有被任何人记录吧. 时常, 或许也称不上时常, 毕竟下雨本来就是少有的事, 我会主动选择淋雨, 雨点一滴一滴点在身上, 很凉, 会打湿衣服, 书包, 还有手里拿着的电脑. 下雨, 是上天在哭吗, 上天存在吗, 如果存在的话, 它也会哭吗, 在哭什么呢, 到底有什么可以哭的呢, 因为气象还是温差呢? 我的眼睛也会没有原因的流出泪水, 或许也有, 我也是天空吗? 滴答, 滴答, 我以为是风扇坏了, 摘下耳机仔细听, 哦, 原来是雨后, 雨, 从窗台上滴下来了.

——2026.9.25凌晨
