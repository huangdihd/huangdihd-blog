# XinManagerServer

XinManagerServer 是 [XinManager](./XinManager) 管理平台的后端服务，基于 NestJS 构建，提供 xinbot 实例的管理、监控和控制功能。它与前端 [XinManagerWeb](./XinManagerWeb) 配合，构成完整的管理平台。

## 功能特性

- 基于 NestJS 框架
- RESTful API 设计
- JWT 身份认证
- 实例状态监控
- 实例远程控制
- 日志管理
