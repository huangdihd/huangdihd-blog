# BackToTheBase

BackToTheBase 是一个 [xinbot](./xinbot) 插件，用来自动触发存放在「滞留室」中的末影珍珠，让玩家可以瞬间传送回基地。在玩家常常需要快速回家的无政府服务器上尤其实用。

## 配置

插件使用位于 `plugins` 目录下的配置文件 `BackToTheBase.json`，可以自定义触发条件以及具体使用哪些末影珍珠等行为。
