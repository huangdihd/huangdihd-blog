# archdeb

archdeb 是一个 Shell 脚本，用来在 Arch Linux 上自动安装 `.deb` 包。`.deb` 本是 Debian/Ubuntu 系的包格式，archdeb 帮你把它在 Arch 上跑起来，省去手动拆包、转换的麻烦。

> 该项目暂无详细说明文档，更多细节可直接查看源码。
