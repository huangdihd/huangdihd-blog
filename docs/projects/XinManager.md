# XinManager

XinManager 是一个用来集中管理多个 [xinbot](./xinbot) 实例的面板。当你同时运行很多机器人时，逐个登录终端管理会非常麻烦，XinManager 把它们统一收拢到一个界面里进行管理、监控和控制。

整个平台采用前后端分离架构：

- [XinManagerWeb](./XinManagerWeb)：前端界面。
- [XinManagerServer](./XinManagerServer)：后端服务。

> 该仓库为平台的聚合/说明仓库，具体实现见前端与后端两个子项目。
