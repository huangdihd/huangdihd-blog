# call_me_as_agent

一个有趣的项目：让你可以像调用 AI agent 一样调用我——一个真人。

它是一个 Web 应用，模拟了 AI agent 的调用界面，但背后实际响应的是一个真实的人。项目提供了一个类似 OpenAI API 的接口，以及一个聊天界面。

## 功能特性

- 模拟 AI agent 的调用体验
- 实时聊天界面
- 真人在背后响应
- 类 OpenAI API 接口
