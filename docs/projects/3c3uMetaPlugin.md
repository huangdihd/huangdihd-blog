# 3c3uMetaPlugin

3c3uMetaPlugin 是一个为 [xinbot](./xinbot) 设计的元插件，专门适配 3c3u.org 服务器。它承担 xinbot 2.x 架构中「元插件」的角色：决定服务器连接地址并处理登录，让本体框架可以服务于更多服务器。

> 该项目暂无详细说明文档，更多细节可直接查看源码。
