# xinRemote

xinRemote 是一个为 [xinbot](./xinbot) 设计的远程控制插件，允许你通过 WebSocket 远程操控自己的机器人实例。

## 功能特性

- **远程控制**：通过 WebSocket 远程控制机器人的移动、视角、交互等操作。
- **实时状态**：实时获取机器人的位置、生命值、背包等状态信息。
- **世界信息**：获取周围方块、实体等世界信息。
- **WebSocket 通信**：基于 WebSocket 的双向通信，低延迟、高效率。
