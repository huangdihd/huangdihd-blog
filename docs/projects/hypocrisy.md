# hypocrisy

hypocrisy 是一个把 [pandora](https://github.com/pengzhile/pandora) 提供的免费 GPT API 伪装成 OpenAI 官方 API 的工具，让那些只认官方接口格式的程序可以直接接入。

## 使用方法

1. 安装 pandora 并获取 access token。
2. 按说明配置后启动，即可得到一个兼容官方格式的 API 端点。

> 这是 2023 年的早期项目，具体步骤请以仓库 README 为准。
