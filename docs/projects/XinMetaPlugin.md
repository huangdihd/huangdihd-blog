# XinMetaPlugin

XinMetaPlugin 是一个为 [xinbot](./xinbot) 设计的元插件，专为 2b2t.xin 服务器优化。它承担了 xinbot 2.x 架构中「元插件」的角色——由外置插件来决定服务器连接地址并处理登录流程，从而让本体保持纯净。

## 功能特性

- **服务器连接管理**：管理 2b2t.xin 服务器的连接地址。
- **登录处理**：自动处理 2b2t.xin 服务器的登录流程。
