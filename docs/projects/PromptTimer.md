# PromptTimer

PromptTimer 是一个 [LangBot](https://github.com/langbot-app/LangBot) 插件，可以在每次对话时自动把当前时间，以及距离上次聊天的时间间隔，加入到提示词中。这让对话模型对「现在几点」「上次聊天过去多久了」有了感知。

## 功能特性

- 自动在用户消息中加入当前时间信息
- 计算并显示距离上次对话的时间间隔
- 时间格式可自定义
- 支持多种时间显示格式
