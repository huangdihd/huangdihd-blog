# XinManagerWeb

XinManagerWeb 是 [XinManager](./XinManager) 管理平台的前端，使用 Vue 构建，提供 xinbot 实例的可视化管理界面。它与后端 [XinManagerServer](./XinManagerServer) 配合，让你在浏览器里就能查看实例状态、下发控制指令。

> 该项目暂无详细说明文档，更多细节可直接查看源码。
