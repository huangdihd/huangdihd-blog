# 4d4vMetaPlugin

4d4vMetaPlugin 是一个基于 [xinbot](./xinbot) 框架构建的专用元插件，适配 4d4v.org 服务器。和其它元插件一样，它负责服务器连接地址的管理与登录处理。

> 该项目暂无详细说明文档，更多细节可直接查看源码。
