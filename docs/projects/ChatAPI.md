# ChatAPI

把你自己装进 OpenAI 的 responses API 里面，扮演 Assistant 和用户聊天（迫真）。

换句话说，它对外暴露一个兼容 OpenAI responses API 的端点，但背后的「模型」其实是你本人——别人以为在和 AI 对话，实际是你在回复。

> 这是一个 fork 项目。我在上游 [fakegpt/ChatAPI](https://github.com/fakegpt/ChatAPI) 的基础上做了实质改动：让它适配了更新的 OpenAI responses API，并增加了若干功能。

## 使用

需要 python3 和一些依赖，clone 之后按 README 配置运行即可。
