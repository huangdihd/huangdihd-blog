# ProjectAI

ProjectAI 是一个基于 LangGraph 与大语言模型构建的项目投影（project projection）系统，用 TypeScript 编写。它借助 LangGraph 的图式编排能力，把大语言模型组织成可控的工作流来完成任务。

> 该项目暂无详细说明文档，更多细节可直接查看源码。
