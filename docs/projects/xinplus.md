# xinplus

xinplus 是一个面向 2b2t.xin 服务器的 [Meteor Client](https://github.com/MeteorDevelopment/meteor-client) addon。与基于 xinbot 的纯发包机器人不同，它是给 Meteor 这款 Minecraft 工具型 mod 编写的扩展，为同一片 2b2t.xin 生态服务。

> 该项目暂无详细说明文档，更多细节可直接查看源码。
